# NeuroVision AI

A clinical-style neurological screening web application for hackathon demo.

## Features
- Hand tremor test using camera
- Drawing test for motor control
- Reaction time test
- Speech test using microphone
- AI risk scoring
- Virtual nurse chatbot
- Dual mode: User Mode + Clinic Mode

## Tech Stack
- **Frontend**: React + Tailwind CSS
- **Backend**: Python Flask
- **ML**: OpenCV, basic audio analysis
- **Database**: SQLite

## Setup

### Frontend
```bash
npm install
npm start
```

### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

## Usage
1. Click "Start Neuro Check"
2. Complete tests sequentially
3. View AI-generated risk scores
4. Consult virtual nurse chatbot
