# Limitations of the Current NeuroVision Evaluation

1. The project does not currently use a clinically labelled dataset.
2. The input features are not derived from genuine neurological measurements; many values are simulated.
3. The risk index is generated through fixed rule-based logic rather than an actual learned model.
4. The project does not demonstrate disease classification performance.
5. The application has not been validated with real patient cohorts or medical experts.
6. Device variability, lighting, microphone quality and browser differences may affect future real-world performance.
7. A single risk score should not be interpreted as a diagnosis.

The present evaluation establishes engineering functionality and prototype behavior, not medical usefulness.
