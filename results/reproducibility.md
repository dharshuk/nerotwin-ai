# Reproducibility Guide

## Environment
- Python 3.10.8
- Windows 11
- Flask 3.1.3
- React 18.2.0
- SQLite backend

## Steps
1. Open a terminal in the project root.
2. Install dependencies:
   `python -m pip install -r backend/requirements.txt`
3. Start the backend:
   `python backend/app.py`
4. Confirm the service responds on `http://127.0.0.1:5000`.
5. Run the existing system test:
   `python test_system.py`
6. Optional: send custom requests to `/user/test`.

## Data collection
The CSV files in this folder were generated by repeated calls to the local `/user/test` endpoint using controlled synthetic values.

## Figures
All figures in the `results/figures` directory were generated from these saved CSV measurements.
